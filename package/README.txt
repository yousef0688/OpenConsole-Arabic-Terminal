OpenConsole - a Windows console with Arabic and Hebrew text support
====================================================================

INSTALL
  1. Extract this whole folder (right-click the zip file, then "Extract All").
  2. Double-click  Install.cmd
  3. Start "OpenConsole" from the Start menu or from the desktop.
     You also get "Open OpenConsole here" in the right-click menu of folders, of folder backgrounds and of the desktop
     (on Windows 11 it is under "Show more options", or press Shift+F10).
     If Visual Studio Code is installed, it gets an "OpenConsole" tab in its panel (Ctrl+J) too, with correct Arabic and Hebrew
     in a terminal. Reload an open VS Code window once (Ctrl+Shift+P, then "Developer: Reload Window").

If Windows shows "Windows protected your PC", click "More info" and then "Run anyway".
The files are not code-signed. No administrator rights are needed.

REMOVE
  Double-click  Uninstall.cmd   (it removes the tab from VS Code as well)

ONLY THE VS CODE TAB (or to add it later)
  Double-click  Install-VSCode.cmd

Everything is installed for the current user only (%LOCALAPPDATA%\Programs\OpenConsole).
The console settings of the rest of Windows are not touched.

OpenConsole - طرفية ويندوز مع دعم كامل للعربية والعبرية

التثبيت
  1. فكّ ضغط المجلد كاملاً (زر أيمن على ملف zip ثم Extract All).
  2. اضغط مرتين على  Install.cmd
  3. شغّل OpenConsole من قائمة ابدأ أو من سطح المكتب.
     وستجد أيضاً "Open OpenConsole here" في قائمة الزر الأيمن للمجلدات ولخلفياتها ولسطح المكتب
     (في Windows 11 تجدها تحت "Show more options"، أو اضغط Shift+F10).
     وإذا كان Visual Studio Code مثبتاً فسيحصل على تبويب "OpenConsole" في لوحته (Ctrl+J) أيضاً، فيه طرفية بعربية وعبرية صحيحتين.
     أعد تحميل نافذة VS Code المفتوحة مرة واحدة (Ctrl+Shift+P ثم "Developer: Reload Window").

إذا ظهرت رسالة "Windows protected your PC" فاضغط "More info" ثم "Run anyway".
السبب أن الملفات غير موقّعة رقمياً. لا تحتاج صلاحيات مدير.

الإزالة
  اضغط مرتين على  Uninstall.cmd   (وهو يزيل التبويب من VS Code أيضاً)

تبويب VS Code فقط (أو لإضافته لاحقاً)
  اضغط مرتين على  Install-VSCode.cmd
